# 普通文本消息处理

当前大肥鱼直接输出普通文本，可按内容使用换行、Markdown、代码和公式。模型请求不设置 JSON Output，也不注入气泡对象协议，不需要 `v/bubbles/emotion/ending/voice` 等字段。API 本身的请求与工具参数仍遵循原有接口格式。

处理流程：普通正文 → 清理内部标记与口癖 → 按配置分句 → 表情组件并回语义气泡 → 逐泡处理末尾句号 → Telegram 发送，或整轮 TTS。

默认启用正则分句 `.*?[。？！~…]+|.+$`；单独换行不保证分泡。正文超过配置中的 150 字符阈值时跳过按句拆分；默认最多 3 个文字气泡，超出部分合并到最后一泡。第一泡立即发送，后续间隔 1.5～3.5 秒。Telegram 4096 字符上限仍由适配器另外切分。

每个最终气泡默认去掉收尾句号，保留中间句号、问号、叹号、代码与链接。只有明确表达不满、冷淡或傲娇时，模型可用内部 `[[KEEP_PERIOD]]` 标记有意保留的句号，标记会在发送前移除。

自动语音由结尾内部情绪标记提名，受全局十分钟冷却控制；用户明确或语境中明确点播时绕过自动冷却，明确只要文字则优先文字。成功只发语音，失败回退文字。原有语音/标点处理不依赖气泡对象协议。

DeepSeek HTTP 原始请求和响应继续由 [1 MiB 有界 API 日志](api-logging.md) 记录。已停用并删除的结构化输出适配不会再产生 `Structured reply rejected` 或额外的格式修复请求；普通网络/API 错误仍走 AstrBot 原有重试机制。
