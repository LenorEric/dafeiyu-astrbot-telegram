# Telegram 指令

主人私聊点击 Start 建立会话；`/sid` 获取当前 AstrBot 会话标识。

| 指令 | 用途 |
| --- | --- |
| `/voice_on` | 开启本会话语音输出 |
| `/voice_off` | 关闭语音输出 |
| `/voice_status` | 查看语音开关 |
| `等等`、`停一下` | 私聊中打断旧回复 |

中文语音指令作为别名保留。扩展的 B站、项目、记忆及作品操作见 [B站活动文档](../deploy/bili_activity/README.md)。LLM 工具名不是 Telegram 菜单指令。

群内通过 @机器人或回复机器人触发；`/指令@机器人用户名` 明确选择目标。主人审批、主动分享和截图只允许在主人私聊使用。
