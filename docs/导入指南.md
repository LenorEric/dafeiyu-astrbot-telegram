# 人格、模型与记忆导入

先完成 [部署](../deploy/README.md)，再在 AstrBot 面板创建人格，将 [大肥鱼人格](../persona/大肥鱼-人格.md) 分隔线后的正文完整导入并设为默认。

对话使用 DeepSeek；图片转述、ASR 和 TTS 使用百炼。配置模型、API 地址及音色，密钥只放在本地安全配置。语音理解独立于语音输出；没有 TTS 音色不影响文字聊天。

长期记忆另行安装 livingmemory 并配置嵌入提供商。所有记忆以 Telegram 会话作用域隔离，不导入其他平台数据库。可按 [课程模板](../persona/课程记忆-模板.md) 手动录入平台无关的行为偏好。

完成后先测试文字，再测试图像和音频。真实效果须以实际收发为准，文档示例不是验收记录。
