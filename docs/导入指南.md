# 人格、模型与记忆导入

先完成 [部署](../deploy/README.md)，再在 AstrBot 面板创建人格，将 [大肥鱼人格](../persona/大肥鱼-人格.md) 分隔线后的正文完整导入并设为默认。

人格 v2.3 增加复杂问题推导、语境与表达打磨，并延续上下文识梗、变体续接与符合角色的幽默反应。升级时，将分隔线后的完整正文更新到已有的“大肥鱼”人格，保留该人格的工具、技能和会话绑定。仅修改仓库 Markdown 不会自动更新 AstrBot 数据库；通过面板保存更新，或在备份后更新数据库并重启服务，以刷新已加载的人格缓存。接梗示例是风格参考，实际效果需要在对话中观察。

对话使用 DeepSeek；当前原生部署的语音输出使用 Breeze Blue，配置见[原生部署指南](native-deployment.md)。图片直接交给支持视觉的模型；ASR 如有需要另行配置。密钥只放在本地安全配置。语音理解独立于语音输出；没有 TTS 音色不影响文字聊天。

当前 `deepseek-flash` 模型在 AstrBot 模型配置的 `custom_extra_body` 中显式传入以下参数，不依赖服务端的思考默认值。它们会合并到 Chat Completions 请求 JSON 顶层；`high` 不保证每轮思考文本的长度。

```json
{
  "thinking": {"type": "enabled"},
  "reasoning_effort": "high"
}
```

长期记忆另行安装 livingmemory 并配置嵌入提供商。所有记忆以 Telegram 会话作用域隔离，不导入其他平台数据库。可按 [课程模板](../persona/课程记忆-模板.md) 手动录入平台无关的行为偏好。

聊天呈现协议由程序单独注入，不需要把它复制进 persona：当前使用 [JSON 气泡协议](json-replies.md)。人格文件负责性格和内容，结构协议负责气泡边界、情绪、末尾句号及语音意图。

完成后先测试文字，再测试图像和音频。真实效果须以实际收发为准，文档示例不是验收记录。
